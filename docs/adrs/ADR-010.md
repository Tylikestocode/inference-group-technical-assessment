# ADR-010: Use Pydantic for typing and validation

- Status: Accepted
- Date: 2026-09-06

## Context

Transaction data, procedure search results, workflow state, and final answers must remain consistent across the application.

## Decision

Use Pydantic models to define and validate application inputs, internal data, settings, and final responses.

## Consequences

- Invalid or incomplete data can be rejected early.
- The expected response format is clear and can be tested directly.
- Model changes require deliberate updates when business fields change.
- Validation does not replace business rules; those remain explicit application logic.
