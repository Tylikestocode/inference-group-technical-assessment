# ADR-003: Use uv for dependency management

- Status: Accepted
- Date: 2026-09-06

## Context

Reviewers need a quick and repeatable way to install and run the project.

## Decision

Use uv to manage Python versions, dependencies, the lockfile, and project commands.

## Consequences

- Local and container builds can use the same locked dependencies.
- Setup commands remain short and reproducible.
- Contributors need uv installed when running outside Docker.
