# ADR-012: Use one controlled agent workflow

- Status: Accepted
- Date: 2026-09-06

## Context

The use case is a short investigation with one clear objective. Multiple autonomous agents would increase complexity without adding meaningful business value.

## Decision

Use one controlled workflow with explicit steps for transaction lookup, procedure search, decision checks, explanation, and validation.

## Consequences

- The system is easier to understand, test, audit, and demonstrate.
- Each service is called only when the workflow reaches the relevant step.
- The solution avoids open-ended planning and model-selected tools.
- More complex future use cases may require additional workflows, not necessarily additional agents.
