# ADR-011: Provide a command-line interface

- Status: Accepted
- Date: 2026-09-06

## Context

The assessment values a small working solution and does not require a polished front end.

## Decision

Provide a command-line interface for building the procedure index and investigating transactions. Support readable output and an optional structured JSON view.

## Consequences

- More delivery time can be spent on the investigation behavior and safe failure handling.
- The solution is easy to script and demonstrate.
- The interface is appropriate for a prototype but not the final employee experience.
