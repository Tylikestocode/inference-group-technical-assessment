# ADR-001: Use Python as the main language

- Status: Accepted
- Date: 2026-09-06

## Context

The prototype needs to combine an AI model, document search, a controlled workflow, validation, and a command-line interface within a short delivery window.

## Decision

Use Python as the main application language.

## Consequences

- The project can use mature AI, workflow, retrieval, validation, and testing libraries.
- The code should be quick to build and straightforward to explain during the walkthrough.
- Python runtime and dependency versions must be fixed so the application behaves consistently across machines.
