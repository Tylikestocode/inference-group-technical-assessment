# ADR-004: Use Ollama for local model serving

- Status: Accepted
- Date: 2026-09-06

## Context

The prototype must use an open-source model and should be able to run within a controlled local environment.

## Decision

Serve Qwen 3.5 9B with Ollama for the prototype.

## Consequences

- The demonstration can run locally without sending transaction data to a hosted AI provider.
- Model setup and invocation are simple.
- The model download is large and performance will depend on the reviewer's hardware.
- The application must return a safe basic response when Ollama is unavailable.
