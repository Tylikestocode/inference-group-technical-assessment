# ADR-017: Test without requiring live AI services

- Status: Accepted
- Date: 2026-09-06

## Context

Automated tests should be fast and reliable even when Ollama, Qwen, or the embedding model is not installed.

## Decision

Design the workflow so tests can replace transaction, retrieval, and AI services with predictable stand-ins. Keep a small optional integration test for the real local services.

## Consequences

- Core workflow, business rules, and failure routes can run in continuous integration without model downloads.
- Test results remain repeatable.
- Real-service integration still needs a separate local check before the demonstration.
- Replaceable interfaces become a tested design feature rather than only a stated intention.
