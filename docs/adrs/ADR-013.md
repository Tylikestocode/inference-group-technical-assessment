# ADR-013: Use a synthetic transaction repository

- Status: Accepted
- Date: 2026-09-06

## Context

The assessment requires a transaction lookup but does not require a production database. Adding PostgreSQL would consume time without improving the core demonstration.

## Decision

Store a small set of fictional transactions in a local JSON file and access them through a read-only repository interface.

## Consequences

- The prototype remains self-contained and quick to start.
- Not-found and service-failure scenarios can be demonstrated safely.
- A real API or PostgreSQL implementation can later replace the JSON repository.
- The JSON file is demonstration data and is not suitable for concurrent updates or production use.
