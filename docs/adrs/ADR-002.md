# ADR-002: Use LangGraph for the agent workflow

- Status: Accepted
- Date: 2026-09-06

## Context

The investigation must follow a visible, controlled sequence and take safe paths when information or services are unavailable.

## Decision

Use LangGraph to represent the investigation as named steps with explicit routes between them.

## Consequences

- The workflow can be demonstrated and tested step by step.
- Success, escalation, and failure routes remain visible in code.
- The solution takes on an additional framework dependency.
- LangGraph will coordinate one workflow; it will not be used to create an open-ended or multi-agent system.
