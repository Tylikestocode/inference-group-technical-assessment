# ADR-009: Extract transaction IDs before the agent workflow

- Status: Accepted
- Date: 2026-09-06

## Context

A transaction number has a known format and is required before any investigation can begin. Asking an AI model to identify it would add uncertainty to a simple task.

## Decision

Extract and validate exactly one transaction ID using normal application code before the request enters the LangGraph workflow.

## Consequences

- Invalid, missing, or multiple transaction IDs are handled consistently.
- No model or downstream service is called for an invalid request.
- The accepted transaction-number format must be clearly defined and updated if business formats change.
