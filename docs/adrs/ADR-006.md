# ADR-006: Package the solution with Docker Compose

- Status: Accepted
- Date: 2026-09-06

## Context

The application, model server, dependencies, and local data must be easy for a reviewer to start together.

## Decision

Package the application with Docker and provide Docker Compose commands to start the application and Ollama services as one solution.

## Consequences

- Reviewers get a consistent environment and a single startup path.
- Model and index data can be kept in named volumes between runs.
- Hardware acceleration and Ollama performance may vary across operating systems.
- A direct uv-based development path should remain available for faster local testing.
