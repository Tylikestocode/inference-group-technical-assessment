# ADR-007: Use FAISS for local vector retrieval

- Status: Accepted
- Date: 2026-09-06

## Context

The agent needs fast local search across four small procedure documents without introducing a separate database service.

## Decision

Use Meta FAISS within the application container to store and search procedure embeddings. Store the matching document details alongside the index.

## Consequences

- Retrieval remains fast, local, and lightweight.
- Docker Compose does not need a separate vector database.
- The index can be rebuilt from the source documents when needed.
- FAISS does not provide document governance, access control, or distributed search; those would be future production concerns.
