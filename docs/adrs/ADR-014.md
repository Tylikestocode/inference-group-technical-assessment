# ADR-014: Use four Markdown procedure documents

- Status: Accepted
- Date: 2026-09-06

## Context

The agent needs a small, understandable body of reference material that demonstrates grounded answers without creating unnecessary content.

## Decision

Create four fictional Markdown procedures covering sanctions screening, high-value or unusual activity, beneficiary verification, and manual review or escalation.

## Consequences

- Reviewers can easily inspect the full source material.
- The documents are simple to edit, version, and rebuild into the search index.
- Each answer can name the procedure used.
- The small synthetic collection demonstrates the approach but cannot prove retrieval quality at production scale.
