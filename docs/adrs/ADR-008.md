# ADR-008: Use a Hugging Face embedding model

- Status: Accepted
- Date: 2026-09-06

## Context

The procedure documents and advisor question need to be converted into comparable representations for search.

## Decision

Use `BAAI/bge-small-en-v1.5` from Hugging Face to create document and query embeddings.

## Consequences

- The same small, open model supports both index creation and retrieval.
- Embedding work can run locally within the controlled environment.
- The model must be downloaded during setup or included in an approved image or cache.
- Changing the embedding model will require rebuilding the FAISS index.
