# ADR-016: Return structured, traceable responses

- Status: Accepted
- Date: 2026-09-06

## Context

An advisor needs a clear answer, while reviewers also need evidence that the answer used transaction facts and the correct procedure.

## Decision

Return a consistent response containing transaction status, hold reason, relevant procedure, recommended next action, human-review requirement, escalation destination, warnings, and a trace identifier.

## Consequences

- Human-readable and JSON views can use the same underlying result.
- Responses can be tested, logged, and reviewed consistently.
- Procedure references make the source of guidance visible.
- When required information is unavailable, the same structure will carry a clear failure or escalation outcome instead of a guessed answer.
