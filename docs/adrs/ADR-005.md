# ADR-005: Keep model and inference providers replaceable

- Status: Accepted
- Date: 2026-09-06

## Context

The prototype uses Qwen and Ollama, while a future bank deployment may use a different open-source model or an approved inference service on Oracle Cloud.

## Decision

Access text generation and embeddings through small application-owned interfaces. Provider-specific code will remain behind adapters.

## Consequences

- Qwen, Ollama, the embedding model, or the serving engine can be replaced without redesigning the workflow.
- Tests can use simple stand-ins instead of running live models.
- The project requires a small amount of extra interface and adapter code.
- The interfaces will cover only capabilities the application currently needs.
