# High-Value and Unusual Activity

- Procedure ID: PROC-002
- Version: 1.0
- Owner: Fictional Transaction Monitoring Operations
- Data label: Fictional assessment data

## When this procedure applies

Use this procedure when verified transaction information identifies an amount
or pattern as high-value, unusual, inconsistent with the recorded activity, or
high risk. This procedure does not define a monetary threshold; it relies on
the classification supplied by the fictional assessment systems.

## Advisor actions

1. Confirm the transaction ID, status, amount, currency, risk level, channel,
   timestamp, and recorded hold reason.
2. Note the verified reason the activity was identified for review and any
   information that is unavailable or inconsistent.
3. Keep the transaction in its current state and refer the verified facts to
   Fictional Transaction Monitoring Operations.

The advisor must not invent a reason for the activity or release, approve,
reject, edit, or bypass the transaction.

## Escalation

Escalate to Fictional Transaction Monitoring Operations when the transaction
is held or high risk, the unusual activity is unexplained, required information
is missing, or the available facts conflict. That team performs the human
review and determines the permitted operational outcome.
