# Sanctions Screening

- Procedure ID: PROC-001
- Version: 1.0
- Owner: Fictional Financial Crime Operations
- Data label: Fictional assessment data

## When this procedure applies

Use this procedure when a transaction is held because screening identified a
possible match to a sanctioned person, organisation, country, or other
restricted party. It also applies when the screening result is incomplete or
cannot be confidently cleared from the verified transaction information.

## Advisor actions

1. Confirm the transaction ID and review only the screening reason and party
   details available in the assessment systems.
2. Keep the transaction in its current state and record the possible match or
   missing information for review.
3. Refer the case, its screening reference, and the verified transaction facts
   to Fictional Financial Crime Operations.

The advisor must not release, approve, reject, edit, or bypass the held
transaction. The advisor must not tell a customer that a sanctions match has
been confirmed when the result is only a possible match.

## Escalation

Escalate to Fictional Financial Crime Operations whenever a possible match is
present, the result is uncertain, required screening information is missing,
or screening services are unavailable. That team performs the human review and
decides the permitted operational outcome.
